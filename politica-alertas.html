Política de privacidad

Alertas de texto · Extensión para Chrome · Versión 2.0.3

Datos y finalidad

La extensión consulta la URL de la pestaña activa cuando abrís el menú para identificar el sitio. Al vincularlo, Chrome solicita permiso para ese sitio. Cuando confirmás una selección, se guardan el texto elegido, el sitio y la ubicación de la página y de la selección. Se conservan también el nombre de la sección y tus preferencias de sonido, pausa y aviso de reaparición.

Con la página abierta, la extensión compara el texto actual con la selección confirmada. Usa el resultado para determinar si cambió, desapareció o volvió. El contenido que aparece en reemplazo se procesa en la pestaña y no se guarda como un historial de cambios.

Almacenamiento y destinatarios

Los datos de configuración se guardan en el perfil local de Chrome. La extensión procesa el texto en el navegador y reproduce sonidos contenidos en su paquete. No transmite los textos ni las URL a servidores del desarrollador o a terceros. No requiere una cuenta, no vende esos datos y no los usa para publicidad.

Control y contacto

Podés pausar o eliminar secciones y desvincular los sitios que elegiste. Desvincular un sitio detiene su seguimiento, y tus selecciones se conservan para que puedas volver a usarlo. Podés administrar los permisos de sitios en Chrome. Al desinstalar la extensión, Chrome elimina su almacenamiento local.

Para consultas sobre privacidad, usá el correo de contacto del editor en la ficha de Alertas de texto en la Chrome Web Store.

El uso de la información obtenida mediante las API de Google respeta la Política de Datos de Usuarios de Chrome Web Store, incluidos los requisitos de uso limitado.

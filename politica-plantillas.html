Política de privacidad

Plantillas de texto · Extensión para Chrome · Versión 1.0.1

Datos y finalidad

La extensión guarda las plantillas que creás o importás, sus títulos y categorías, favoritos, preferencias y asignaciones a atajos. Al elegir un archivo o respaldo, lee su contenido en el navegador para mostrar una vista previa y guardar las plantillas que confirmes.

Para pegar, accede temporalmente a la pestaña activa cuando invocás la extensión. Comprueba el campo editable, su contenido y la posición del cursor o la selección para colocar la plantilla. Este contexto es temporal. Las páginas y sus contenidos no se incorporan a la biblioteca por esta operación. Cuando elegís copiar una plantilla, la extensión coloca ese texto en el portapapeles.

Almacenamiento y destinatarios

La biblioteca y las preferencias se guardan en el almacenamiento local del perfil de Chrome. La extensión no requiere una cuenta, no sincroniza la biblioteca ni la transmite a servidores del desarrollador o de terceros. No usa esos datos para anuncios ni los vende.

Si pegás o copiás una plantilla en un sitio, ese sitio puede tratar el texto que decidas ingresar de acuerdo con su propia política. Al exportar un respaldo se crea un archivo con el contenido completo de la biblioteca. Vos elegís cómo conservarlo o compartirlo.

Control y contacto

Podés ver, editar y eliminar plantillas desde Gestionar. Los datos se conservan en el perfil hasta que los elimines o desinstales la extensión. Los respaldos exportados se gestionan como archivos aparte.

Para consultas sobre privacidad, usá el correo de contacto del editor en la ficha de Plantillas de texto en la Chrome Web Store.

El uso de la información obtenida mediante las API de Google respeta la Política de Datos de Usuarios de Chrome Web Store, incluidos los requisitos de uso limitado.
